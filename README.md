# 嵌入式系统

基于 TI Tiva C TM4C123GH6PM / EK-TM4C123GXL 开发板的四个 Code Composer Studio 实验工程。

| 工程 | 内容 |
| --- | --- |
| `嵌入式系统/Lab1_LED_Button` | LED 与按键实验 |
| `嵌入式系统/Lab2_ST7735` | ST7735 显示屏实验 |
| `嵌入式系统/Lab3_Clock` | 基于显示屏的时钟实验 |
| `嵌入式系统/Lab4_Clock_WiFi` | ESP-01S 联网、SW1 按键同步北京时间及 UART 日志 |

## 导入与编译

1. 下载整个仓库或使用 Git 克隆。
2. 在 CCS 中选择 **Project → Import CCS Projects**，搜索 `嵌入式系统` 文件夹。
3. 选择所需的四个实验工程；不要另外导入工程内的 `driverlib` 子工程。
4. 采用项目配置的 TI ARM 编译器 **20.2.7.LTS**，构建对应工程，然后下载到开发板。

保留了各工程的 CCS 配置、启动文件、链接文件、头文件与 DriverLib。`driverlib/ccs/Debug/driverlib.lib` 是所需库文件，有意保留；工程自身的编译输出与调试会话未上传。

## 实验四

- 在实验三时钟基础上，按板载 **SW1（PF4）** 请求 NTP 时间并同步到北京时间（UTC+8）。
- ESP-01S 通过 UART1 与开发板通信；UART0 通过开发板调试 USB 向电脑输出校时过程。
- 电脑串口助手设置为 **115200、8 位数据、无校验、1 位停止位**，用文本方式接收。
- 接线与操作步骤见 `嵌入式系统/Lab4_Clock_WiFi/docs`。
- `wifi_config.h` 中不包含热点密码。当前配置可使用 ESP 已记住的热点；更换设备或热点时，请按工程说明在本地配置。不要向公开仓库提交真实密码。
- 按键校时与 UART 输出已在原硬件上验证。串口号和热点环境应按实际电脑、手机配置。

## 第三方代码

`driverlib` 与 `inc` 内包含 Texas Instruments 提供的代码；请保留并遵守各文件中的原有版权及许可声明。本仓库未将这些第三方文件重新授权。
